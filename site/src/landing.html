Why it fits
01

No framework

One script of about 42 KB gzipped with everything inside. No React and no build step. With a bundler, install the npm package and call define() once.

02

Your CSS wins

It draws into your page, with no shadow DOM. Its own rules have zero specificity, and its colours are --dv-* variables you set on any parent.

03

Small lists or server pages

Hand it every row and it searches, sorts and pages in the browser. For long lists, register an adapter and the server answers one page at a time.

04

Phones and keyboards

Tables become cards on small screens, with 44 px tap targets and no sideways scrolling. Every control works from the keyboard.

The parts

Take the whole list, or one piece of it

Each part is a tag and a small package of its own. The list’s script already includes all of them.

<lfdln-data-viewer>The listTable or cards with search, filters, sorting, pages and row menus. <lfdln-menu>MenuKeyboard, headings, disabled items that say why, and a built-in confirm. <lfdln-pagination>PaginationPrevious and Next, numbered pages and Rows per page for any list. <lfdln-card>CardA title, badge, picture, header menu and footer actions, in HTML. <lfdln-search>SearchA search box with Search in, as you type or on submit. <lfdln-filter>FilterChoices, ranges and yes-or-no parts, with chips for what is applied.

Add it in a minute

Install from npm for an app with a bundler, or copy one standalone script onto a plain page. Works in Chrome and Edge 123, Safari 17.5 and Firefox 125, or newer.
