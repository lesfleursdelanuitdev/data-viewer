data-viewer, selecting rows

The select add-on: a box on every row and card, and the selection bar while anything is ticked. Esc in the bar, or ✕, clears it. #table and #server have batch actions; set window.keep = true to make their dv-batch handler call preventDefault().

#table: a table

#cards: cards

#cardof: cards from cardOf

#tpl: custom cards (cardTemplate)

#mount: custom cards (cardMount)

#heads: built-in cards with a ⋯ menu (box top left, ⋯ top right, the title below)

#tplhead, #mounthead, #htmlhead: custom cards that put pieces.select and pieces.menu in their own header

#mountlate: cardMount that places pieces.select later (as React does, in an effect)

#compact: a compact list

#server: from a server (json adapter, 45 recipes)

#nokey: a row with no id

#views and #sentence: selectable with a filter style drawn above the bar
